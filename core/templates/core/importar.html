Como funciona

  1. Selecione um ou vários PDFs, inclusive o carnê do ano inteiro que o sócio envia.
  2. O sistema lê cada boleto: linha digitável, valor e vencimento, conferindo os dígitos verificadores.
  3. O cliente é identificado pelo CPF/CNPJ do PDF ou pelo cliente selecionado.
  4. Cada boleto vira uma cobrança mensal, com o envio agendado para {{ cfg_global.dias_antes_vencimento }} dias antes do vencimento e o lembrete para {{ cfg_global.dias_apos_vencimento }} dias depois, se não for pago.
  5. Divergências (valor diferente do cadastro, página com vários boletos) viram tarefas de revisão.

PDF escaneado (imagem) não pode ser lido: cadastre a cobrança manualmente e anexe o PDF.
